# Stellar Spark

Stellar Spark is a dynamic web application designed for event management and hosting. It allows users to create, edit, and manage events seamlessly, providing a user-friendly interface for both event organizers and attendees. The application is built using React and Vite, with a focus on responsive design and real-time data handling.

## Features

- **Event Creation and Management**: Users can create new events by filling out essential details such as title, description, location, date, time, and type. The application supports uploading photos and selecting event features, enhancing the event's appeal.

- **User Authentication**: Stellar Spark incorporates a secure authentication system, allowing users to register, log in, and manage their profiles. This ensures a personalized experience and easy access to user-specific features.

- **Responsive Design**: Built with a mobile-first approach using Tailwind CSS, the application is fully responsive, providing an optimal viewing experience across various devices.

- **Real-time Data Handling**: Utilizing Axios for API calls, Stellar Spark fetches and updates event data in real-time, ensuring users have the latest information at their fingertips.

- **Community Engagement**: The platform encourages community interaction by allowing users to RSVP for events, view upcoming events, and manage their participation.

## Technologies Used

- **Frontend**: 
  - React
  - Vite
  - Tailwind CSS
  - Axios

- **Backend**: 
  - Node.js
  - Express
  - MongoDB
  - JWT (JSON Web Tokens)

## Getting Started

To get a local copy up and running, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/stellar-spark.git
   ```

2. **Navigate to the client directory**:
   ```bash
   cd stellar-spark/client
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```

5. **Navigate to the API directory**:
   ```bash
   cd ../api
   ```

6. **Install dependencies**:
   ```bash
   npm install
   ```

7. **Start the backend server**:
   ```bash
   npm start
   ```
